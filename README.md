# しりとり最長探索ツール

## 概要
今回は中央競馬のG1レースおよび地方競馬のジーワン級競争を題材として、  
最長で成立する馬名しりとりを作成する。　　

## 作成に至った経緯
かつてポケモンで最長しりとりの作成を試みたものがいた。  
辞書でしりとりを行う、といった内容の研究をもとに彼は人力で制作を行ったが、  
[参考文献](http://www.co.mi.i.nagoya-u.ac.jp/~yagiura/topics.html)  
現在はマシンスペックの向上、AI技術の発展もあって、探索アルゴリズムを作成することは容易となった。  
<br>
しかしながら、このような探索アルゴリズムを人間が改めて考え、プログラムを構築することは  
情報処理を学んでいる学生として大きな意義があると考える。  
<br>
当プログラムでは、最長しりとりの作成に当たって、筆者自身がアルゴリズムを考え、コーディングを行い  
技能の向上を図ることを目的とする。  
<br>
また、題材として、筆者が競馬観戦を趣味としておりデータ数の都合がつきやすいことから、  
競走馬の名前を題材としてアルゴリズム構築を行う。
